# SpeechProcessingProject

In this repository, I am presenting my assignment for the course Speech Processing Algorithms. The
assignment is divided into two parts. In the first part, I implemented some basic algorithms on
a simple speech signal, while in the second part, I created a vowel synthesizer and used it to
synthesize six vowels. The algorithms in the first part offer high accuracy and have been widely
used in speech processing, especially before the Neural Network era. The vowel synthesizer
in the second part aims to mimic the human vocal system, which is described on my report analytically, 
and produce vowels digitally. For simplicity, the synthesizer is operating at a constant
fundamental frequency (125Hz), whereas in human speech, this frequency varies between 50Hz
and 400 Hz. Despite this limitation, the synthesizer produces remarkable results, allowing the
vowels to be easily distinguished. The project has been fully developed in Python, specifically
using Jupyter Notebook, allowing the user to view and interpret the results easily at each step.
